\newcommand{\experimentnote}{%
  \par\smallskip
  \parbox{\textwidth}{\footnotesize\raggedright
    \textit{Note.} Values are computed from \texttt{result\_ds}. Acc. is
    accuracy (\%); Token is the mean number of generated text tokens per
    problem; Time is the mean elapsed time per sample in seconds. Unless
    marked with $\dagger$, entries are averages over eight repetitions
    (seeds 42--49). $\dagger$ denotes a currently incomplete aggregate:
    Identical--Hierarchical on AIME25 uses three repetitions and
    Soft--Sequential on AIME25 uses two. Improve compares the better of
    Kernel and Kernel-ES with TextMAS; missing experiment combinations are
    denoted by $-$.}}
